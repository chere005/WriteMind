WriteMind 2.8.0

- **File ▸ Language Setup…** (every platform): shows the Wolfram and Python (and C, C++, Rust) each kind of runnable cell uses, tests it, lets you choose another (a virtual environment, a different Wolfram Engine), and offers to get or install what is missing (on Windows: the same Python / Wolfram Engine install and Wolfram activation the installer offers).
- **Windows installer:** the Python / Wolfram Engine page is fixed (winget output, per-user Python with the py launcher, restart-needed and declined-prompt results reported).
- **Mac:** Homebrew's Python and wolframscript are preferred over the system's.
