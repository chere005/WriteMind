WriteMind 3.9.0

- **Bullets: a newline adds another bullet, and another on a blank one removes it, without leaving the cell.** Return on a bullet, numbered item, to-do or quote line adds the next one; Return on that one when it is blank takes its marker off and leaves the line, a newline after the list inside the same cell (it is no longer exited into the bar); the Return after that puts the bar with the + under the cell. The same on the markdown side and on the rendered page.
