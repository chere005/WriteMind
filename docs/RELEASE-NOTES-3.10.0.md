WriteMind 3.10.0

- **Ctrl+Enter adds a new line without leaving the cell.** (⌘↩ on a Mac.) Press it again and again: every line, empty ones too, stays in the same cell. In a list the new line belongs to the item; Return after it adds the next item. Format ▸ New Line in Cell does the same.
- **A new bullet or checklist puts the cursor where you type.** The List button, the Style menu, the + and Shift+Ctrl+L leave a real item with the cursor just past the bullet or box, on both the markdown side and the rendered page.
- **Typing `*` on the horizontal cursor starts a bullet list,** ready for its first item.
- **Bullets and a checklist under them are one cell.** Dots, dashes, numbers and to-dos written one under another stay one cell; each item keeps its own look, and Style names the one you are on.
