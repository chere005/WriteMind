WriteMind 2.11.0

- **File ▸ Export ▸ Wolfram Notebook…** writes a .nb: headings, text, lists, tables, code, runnable cells (Wolfram as Input, Python as ExternalLanguage) and maths; drawing cells, floating ink and pictures become Images (the Wolfram Engine imports their SVG; without an engine each is an Input cell that does it when evaluated).
- **Copying drawing cells** puts something a Wolfram notebook pastes as the image itself (on the Mac, the front end's own pasteboard type), without disturbing WriteMind-to-WriteMind paste.
