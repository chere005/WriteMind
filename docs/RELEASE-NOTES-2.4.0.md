WriteMind 2.4.0

- **Mac:** Update now downloads and installs the update and restarts into it (from this version on; a copy older than 2.4.0 opens the release page once more).
- **Updates:** a startup check that fails is tried again, and WriteMind looks again every few hours while it runs.
- **Tablet sheet:** Bring in (Writing, Page, Drawing Cell) leaves the writing on the sheet; the next Undo takes the capture back from the note.
