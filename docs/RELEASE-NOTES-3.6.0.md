WriteMind 3.6.0

- **Read the pen's handwriting on the note page.** Pick the strokes the pen wrote on the rendered page (a marquee, or a click on one) and the bar over them has a Read button: it reads the handwriting as words and types them into the note just under the lowest stroke. The strokes stay. It is the same reader as the camera's Text and the Wacom sheet's As Text, and it is only there where the app has a reader.
- **The Read button is an icon, not "Aa".** "Aa" is the toolbar's Font and Colour and the bar's Label, so a picture's read button is now a scan-text icon with a tooltip, and so is the new one for handwriting.
- **The Quick Reference** names it.
