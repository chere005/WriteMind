WriteMind 3.2.0

- **The video pane's tabs are the notebook's tabs.** The Live and Page tabs of the camera, and the Sheet tabs of the tablet, are now the same row as the one over the note: 36px high, the tab in front in the picture's colour with no underline, a × on it and under the pointer, and the same + at the end. Closing a page or a sheet that holds something still asks first ("Close?").
- **The Quick Reference is up to date** for the new UI: the toolbar, the one-button pen, the tab row, Search Notes (⇧⌘F), the sidebar's bar, undo that reaches the last three file steps, and the pane's tabs, each line held by a test to the control it names. Help ▸ Quick Reference brings an older copy up to date.
